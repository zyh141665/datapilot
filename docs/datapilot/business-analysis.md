# 经营指标、月份对比与图表

这一轮在原有数据集上传、会话绑定和查询上增加：

- 销售额、所选成本、差额利润、利润率。
- 月度趋势、本期与基期的销售额变化及增长率。
- 按区域、商品等字段拆分销售额变化，保留新增和消失的分组。
- 折线图、柱状图、数值明细、字段映射、计算口径和文件来源。
- 同一套计算支持工作台手动操作和 Agent 工具调用。

### 再验证 Agent 调用

从这份数据点击“打开分析对话”，发送：

> 请先查看当前数据集结构。以“月份”为日期、“销售额”为销售额、“成本”为成本、“区域”为贡献分组，单位按元演示。比较 2026 年 10 月和 9 月的销售额变化，计算增长率与各区域的变化贡献，并展示趋势图和贡献图。请实际调用经营分析工具，并如实说明缺失数据的影响。

预期执行：结构查看 → `analyze_business` → 工具计算结果、图表 → 模型解读。经营分析工具本身已经返回两张图，无需重复调用图表工具。

随后可追问：

> 请使用图表工具，只统计 2026-10，各区域销售额求和，画一张柱状图。

这次应调用 `create_dataset_chart`，图中应为华东 16,300、华北 13,700。工具先筛选再聚合，模型不能直接提交一组自行编造的图表数值。

刷新对话后，已保存工具结果的图表应继续显示。普通文字回答、失败的工具结果或没有对应调用的结果不能生成分析卡片。

## 指标口径

- 差额利润 = 所选销售额 − 所选成本。仅代表这两个字段之差，不自动纳入税费、退款或运费。
- 利润率 = 差额利润 / 销售额 × 100%。使用汇总后的比值，不对每行利润率简单求平均；销售额须为正。
- 增长率 =（本期 − 基期）/ 基期 × 100%。基期为零或负数时不显示增长率，仍可展示变化额。
- 分组变化 = 分组本期销售额 − 分组基期销售额。分组在其中一个有观测数据的月份没有记录时，该期按零处理。
- 贡献占比 = 分组变化 / 总变化 × 100%。它可能为负数或超过 100%，总变化为零时不计算占比。这说明的是变化构成，不能证明因果关系。
- 日期缺失的行会计数并排除。无效或含糊日期会要求修正。没有记录的整个月份保留空缺；相关数值存在缺失时不以零填补。
- 默认本期取范围内最新有记录月份，默认基期取上一个日历月；不会跳过空月拿更早月份冒充上月。基期和本期都使用所选分析范围内的样本。
- 经营分析最多 24 个连续月份、50 个贡献分组；独立图表最多 50 类。超限会要求缩小范围或增加筛选，不会悄悄截断成“全部结果”。
