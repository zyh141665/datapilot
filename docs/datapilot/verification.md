# DataPilot 数据集工作流验收

本轮实现：CSV/XLSX 上传 → 当前账号的数据集 → 会话绑定 → 工具查询 → 模型解释。

## 启动

依赖和当前机器上的扩展配置已更新。若旧服务仍在运行，先在启动窗口按 Ctrl+C 停止，然后在 CMD 执行：

```bat
call D:\量化agent\tools\deerflow-env.cmd
cd /d D:\量化agent\open-source\deer-flow
make dev
```

打开 `http://localhost:2026/workspace/data`，使用已有账号登录。扩展在 Gateway 启动时加载，因此修改配置后需要重启。

新检出项目需要先安装依赖，再运行 `backend\.venv\Scripts\python.exe scripts\datapilot_setup.py`；此脚本保留其他配置，不显示密钥。机器相关配置和 SQLite 数据均不提交到 Git。

## 手动验证

1. 点击“导入演示数据”。这是模拟数据。预览应显示 **8 行、4 列、1 个缺失单元格**。
2. 点击“打开分析对话”，确认输入框上方选中了这份数据。打开页面和选择数据本身不调用模型。
3. 发送：**先查看当前数据集结构，再调用查询工具，按区域汇总销售额，并计算总销售额。请根据工具结果回答。**
4. 应看到数据结构/查询工具的执行结果，并得到：**华东 54,900、华北 45,900、合计 100,800**。最终文字相符还不够，应同时查看工具执行记录。
5. 在同一对话追问：**销售额大于 12,000 的记录有几条？列出月份、区域、销售额，按销售额降序排列。** 应返回 **5 条**，第一条是 **2026-10、华东、16,300**。无需重新上传。
6. 刷新页面后，这个对话应继续显示绑定的数据集；重启服务后，数据集仍应存在。要分析另一份数据，请新建对话。
7. 可上传一个有两个工作表的 XLSX：应先出现工作表选择，确认后才保存。含公式的表会提示先转为值，不会替你计算公式。

真实模型的工具选择、连续追问和浏览器运行效果由用户执行上述步骤验证；离线测试不能替代这些验证。

## 当前范围

数据集基础工具：`list_datasets`、`describe_dataset`、`query_dataset`；原有 `analyze_csv` 文本统计工具保留。后续已增加经营分析和图表工具，见[经营分析验收](business-analysis.md)。部署时宿主会为插件工具名添加命名空间。

支持筛选、字段选择、最多两个字段分组、求和/均值/计数/最小值/最大值、排序。查询返回实际计算结果、查询条件与文件 SHA-256；模型不能传入原始 SQL、代码或其他用户的数据集编号。

当前限制：每文件 5 MiB、10,000 行、50 列，每账号最多 20 份数据集。尚无数据集删除、报告导出、多表关联或预测。经营指标和图表已加入，另有范围限制，见[经营分析验收](business-analysis.md)。统计结果不能直接证明业务变化的原因。

业务代码入口：[数据集存储与查询](../../examples/datapilot-analysis/datapilot_analysis/datasets.py)、[公开扩展与模型工具](../../examples/datapilot-analysis/datapilot_analysis/plugin.py)、[数据工作台](../../frontend/src/components/workspace/data-workbench.tsx)。
